# Modern Computers – e-Sevai Center Website

A modern, responsive, and user-friendly website developed for **Modern Computers e-Sevai Center**, Tiruvannamalai. The website provides an organized platform to showcase various **Tamil Nadu Government e-Sevai, CSC, computer, and general digital services**.

## 🌐 About the Project

**Modern Computers** is an e-Sevai and digital service center that helps customers access various government and computer-related services through a simple and convenient platform.

This website was developed to provide:

* Easy access to available services
* Clear categorization of e-Sevai and CSC services
* English and Tamil language support
* Responsive design for different screen sizes
* Simple and user-friendly navigation
* Professional presentation of the service center

## ✨ Features

* 🏠 **Home Page** – Introduction to Modern Computers
* 🏢 **About Section** – Information about the service center
* 📋 **e-Sevai Services** – Government certificate and online services
* 🖥️ **CSC Services** – Common Service Centre related services
* 💻 **Computer Services** – Computer and digital-related services
* 📄 **General Services** – Additional customer services
* 🌐 **Language Switcher** – English and Tamil language support
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile devices
* 📞 **Contact Section** – Center address and contact information
* 🎨 **Modern UI** – Clean layout with smooth hover effects and navigation

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/modern-computers.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd modern-computers
```

### 3. Run the Website

Open `index.html` in a web browser.

For the best development experience, you can use **Visual Studio Code with the Live Server extension**.
